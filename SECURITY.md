# Security policy

Use [GitHub private vulnerability reporting](https://github.com/Nodrail/nodrail-server/security/advisories/new)
for security issues in the API, console, database access or self-hosted
deployment. Include the affected release, reproduction steps and the impact.
Remove credentials and private policy or run data from attachments.

We aim to acknowledge reports within three working days. Security fixes are
made in the latest release.
