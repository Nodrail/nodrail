# Security

Please report vulnerabilities privately, through
[GitHub's private reporting](https://github.com/Nodrail/nodrail-js/security/advisories/new)
or to hello@nodrail.com, with steps to reproduce. Do not open a public issue.

Most useful: a deciding or publishing tool offered without its flag or scope,
a decision or publish made without the person confirming when the client
supports elicitation, or a token sent anywhere but the Nodrail address you
chose. Include the version and the MCP client.

Fixes go to the latest release. That an assistant given `--allow-decisions`
can be talked into deciding by text an agent wrote is why the flag exists and
is off by default, not a vulnerability.
